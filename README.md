# Minecraft Knightly Arsenal Plugin

Knightly Arsenal is a Minecraft plugin that installs a bundled datapack with medieval-inspired weapons and knight armor in iron, diamond, and netherite variants. The datapack provides an arming sword, war axe, war hammer, and a four-piece armor set for each material tier.

## Install

1. Use a Paper server running Minecraft 1.21.11 with Java 21.
2. Place the plugin JAR in the server's `plugins` folder.
3. Restart the server. The plugin installs the datapack into each world loaded at startup.
4. Run `/reload` or restart the server to load the datapack.

## Use

1. In game, run `/function historical_arsenal:armory`.
2. Receive one arming sword, war axe, war hammer, helmet, chestplate, leggings, and boots from each of the iron, diamond, and netherite tiers.
